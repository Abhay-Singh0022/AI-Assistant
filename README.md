# AI Assistant

A Python-based voice-controlled AI desktop assistant that can recognize voice commands, speak responses, open websites, play music, and fetch the latest news.

## Features

- 🎙️ Voice command recognition
- 🔊 Text-to-speech responses
- 🌐 Open websites using voice commands
- 📰 Fetch latest news using NewsAPI
- 🎵 Play songs from a custom music library
- 🇮🇳 Supports Indian English speech recognition
- 🎤 Ambient noise adjustment for better voice recognition
- ⚠️ Error handling for speech and API requests

## Technologies Used

- Python
- SpeechRecognition
- pyttsx3
- Requests
- PyAudio
- python-dotenv
- NewsAPI
